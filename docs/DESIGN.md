# Design

The landing page is the Makro Framer template rebuilt as a coded site (`apps/web/framer`, data from `design/makro/build.mjs` and `design/makro/copy.json`). Dashboard images are re-rendered with Clawback content by the tools in `design/render`.

The product app uses the same tokens: Inter Display, ink `#242426`, canvas `#EBEFF5`, white cards, lime `#D9FF5C`, dark `#35363B`. Styles live in `apps/web/app/(product)/product.css`.
