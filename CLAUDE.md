# Overpaid (repo dir `ombud`)

Overpaid finds money people are owed and gets it back: Find (receipts and statements to one ledger), Fix (a fleet of AI browser agents on merchants' own sites), specialist hires paid over x402 into Masumi escrow, and Bloc group bargaining settled by an Aiken contract. Cardano preprod only. Formerly named Ombud (`docs/DECISIONS.md` D1).

After any context reset read: this file, `docs/PLAN.md`, `docs/PROGRESS.md`, `docs/DECISIONS.md`. Scope and facts: `docs/BRIEF.md`. Grounded research: `docs/research/*.md`.

## Layout
- `apps/web` Next.js 16: landing page at `/` (Framer runtime copy of the Makro template, `framer/`), product at `/app/*`, phone page `/join`. Product UI code in `apps/web/product/`, styles `app/(product)/product.css`.
- `services/api` Fastify :4000, orchestrator, SSE `/api/events`, holds the buyer key.
- `services/fleet` :4500 browser fleet (no keys, no payment tools). `services/merchants` :4101-4104 four demo merchants.
- `services/specialist` :4200 x402 masumi seller. `services/bloc` :4300, `services/providers` :4400.
- `packages/shared` types, evidence hashing, `demo-world.ts` (single source of truth for demo data). `packages/db` Drizzle schema. `packages/find` Find pipeline. `packages/cardano` wallets, escrow tx builders, buyer. `contracts/bloc` Aiken.

## Commands
- `pnpm install`, then `pnpm db:migrate` (Postgres at `postgres://localhost:5432/overpaid`, Homebrew, no Docker).
- `pnpm dev` runs services and web. `pnpm demo:reset`, `pnpm demo:check`.
- Secrets: `.env` (copy `infra/env/.env.example`) and `.env.wallets` (three seeds, generated by `scripts/gen-wallets.ts`). Never print or commit them.
